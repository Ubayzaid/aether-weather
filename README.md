# Aether Weather

Website cuaca responsif Aether Weather 2.0 dengan atmosfer dinamis, animasi halus, kartu interaktif, dan tampilan premium yang terinspirasi aplikasi cuaca Samsung dan Google.

## Fitur
- Cuaca saat ini, suhu terasa, kelembapan, angin, peluang hujan, UV, tekanan, awan, dan jarak pandang.
- Prakiraan per jam selama 24 jam dan prakiraan 7 hari.
- Pencarian kota di seluruh dunia.
- Deteksi lokasi perangkat (memerlukan izin browser).
- Mode Celsius/Fahrenheit dan tema terang/gelap.
- Latar belakang dan atmosfer visual berubah mengikuti kondisi cuaca.
- Animasi micro-interaction pada kartu, pencarian, ikon, dan pembaruan prakiraan.
- Tampilan glassmorphism yang lebih halus, hierarki tipografi lebih tegas, dan transisi responsif.

## Menjalankan di VS Code
1. Ekstrak ZIP.
2. Buka folder `aether-weather` di VS Code.
3. Jalankan `index.html` dengan ekstensi **Live Server** (klik kanan > Open with Live Server).
4. Pastikan komputer terhubung ke internet.

## API
- Forecast: https://api.open-meteo.com/v1/forecast
- Geocoding: https://geocoding-api.open-meteo.com/v1/search
- Reverse geocoding: https://geocoding-api.open-meteo.com/v1/reverse

Open-Meteo tidak memerlukan API key untuk penggunaan gratis non-komersial. Berikan atribusi kepada Open-Meteo sesuai ketentuan lisensi data CC BY 4.0. Periksa ketentuan terbaru jika digunakan secara komersial.

Dibuat dengan HTML, CSS, JavaScript, dan Open-Meteo.
